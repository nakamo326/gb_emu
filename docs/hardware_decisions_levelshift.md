# ハードウェア設計決定事項 — 実カートリッジのレベル変換

> 安全訂正: cart /RESETはカート側からLOW駆動され得るため、245のpush-pullから外す別open-drain案が必要です。旧/RESET配線は使用しないでください。B側bus-holdは/OE無効でも動作するため、弱pullで安全HIGHを保証できません。[安全条件](teensy_cart_safety.md)を優先してください。

> 2026-10-05: 以下は旧SN74LVC16T245単体IC・/OE常時L構成の記録です。新採用のAE-LLCNV-LVCH16T245 ×2とP9/P10 /OE制御は[ピン見直し計画](teensy_outer_pin_plan.md)を参照。旧47kΩ信号プル抵抗とICピン番号を新モジュールへ流用しないでください。新構成の実カート動作は未検証です。

## 決定

**SN74LVC16T245 を 2 個**使い、Teensy 4.1（3.3V）と GB カートリッジ（5V）の 28 本の信号を変換する。A 側を Teensy、B 側をカートに統一し、VCCA=3.3V、VCCB=5V とする。U1 の 16ch は A0–A15、U2 のバンク 1 は D0–D7、バンク 2 は /RD・/WR・/CS・/RESET に割り当てる。U2 バンク 2 の 4ch は未使用。

| IC / バンク | DIR | /OE | 用途 |
|---|---|---|---|
| U1 / 1、2 | 3.3V | GND | A0–A15、常に A→B |
| U2 / 1 | Teensy pin 33（/RD） | GND | D0–D7、/RD=H で A→B、L で B→A |
| U2 / 2 | 3.3V | GND | 制御 4 本、常に A→B |

4 本の /OE は GND に固定し、P42 は使用しない。カート側の /RD・/WR・/CS には、Teensy の GPIO が Hi-Z のとき非アサート側へ倒す 5V プルアップを設ける。TI は電源立ち上がり中に /OE を VCCA へプルアップし、両電源が安定してから有効化するよう指定しているため、この簡易配線はその電源シーケンスを満たさず、立ち上がり中の IC 出力状態は保証しない。[TI データシート](https://www.ti.com/lit/ds/symlink/sn74lvc16t245.pdf)

GB カート側では /RD・/WR・/CS を H に保てば待機状態になる。P42 による /OE 制御はカートリッジのバス仕様上は必須でないため、いったん省く。以前の SN74LVC8T245 にも同種の /OE プルアップ推奨があり、16 ビット品への変更で新たに生じた条件ではない。

## 選定理由

- 5V 電源の 74AHCT245 をデータバスの読み出し方向で使うと Teensy 側に 5V が出る。2 電源品なら、B→A の出力は VCCA=3.3V に収まる。
- 16 ビット品は 8 ビット単位で DIR を独立制御できるため、同じ U2 で双方向データ 8 本と単方向制御 4 本を扱える。
- DIR と /OE は VCCA 基準。U2 のデータバンクの DIR は Teensy の /RD で直接制御でき、専用 GPIO やインバータは不要。
- 4 個の 8 ビット IC（74AHCT245 ×3、SN74LVC8T245 ×1）から 2 個へ減る。配線の詳細は各 IC のピン配置が異なるため、必ず新しい配線表を使う。

## 起動時とバスの状態

Teensy 側の /RD・/WR・/CS・/RESET は各 10kΩ で 3.3V へ、カート側は各 10kΩ で 5V へプルアップする。D0–D7 は Teensy 側を 47kΩ で 3.3V、カート側を 47kΩ で 5V にプルアップする。A0–A15 は両側を 47kΩ で GND へプルダウンする。未使用の U2/2 A 入力は GND、対応する B ピンは 47kΩ で GND に接続する。これらは TI が示す「A/B 両側の入力回路は常時有効」という条件に合わせ、GPIO が入力の間も信号が浮かないようにするためである。

データバスの方向は Teensy pin 33 の /RD で決まる。読み取りでは /RD=L と同時に U2/1 が B→A となり、Teensy の D0–D7 は入力のまま読む。書き込みでは /RD=H で A→B とし、Teensy が D0–D7 を出力してから /WR を L にする。したがって現在の `GpioCart::read` / `write` のバス手順は維持できる。

## 電源と実装

カート VCC は Teensy VIN（USB 5V）から供給する。U1/U2 の VCCA と VCCB それぞれに 100nF、カート VCC に 100nF と 100µF を置く。採用する `SN74LVC16T245DGGR` は TSSOP-48（0.5mm ピッチ）。ピン番号と接続は [配線ガイド](real_cart_wiring.md) を参照する。実機はまだ未検証のため、通電前の電源・/OE・DIR の導通確認と段階的な読み書き確認が必要。

## 旧案からの変更

旧案ではデータバスに単方向 245 を 2 個使う構成があったが、同じネットを並列駆動する危険があった。その後、74AHCT245 ×3 と SN74LVC8T245 ×1 の計 4 個に変更した。今回の 2 個構成では、U2 の 2 バンクを独立に制御して信号を分けるため、並列駆動は発生しない。
